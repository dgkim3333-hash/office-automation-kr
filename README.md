# 사무 자동화 — PDF 를 엑셀 장부로 (office-automation-kr)

> [!IMPORTANT]
> **모든 실행은 내 PC 에서, 채팅 탭이 아니라 Code 탭으로만 합니다.** (Cowork·클라우드 세션도 쓰지 않습니다.)
> - **`run.bat` 처리는 이 PC 안에서만 돌고 인터넷으로 아무것도 보내지 않습니다.** 프로그램은 클라우드에서 실행되면 스스로 멈추고, 실행하는 동안 인터넷 연결을 코드로 막습니다.
> - **Claude 에게 보여 준 것만 Claude 에게 갑니다.** Code 탭에서도 Claude 가 연 파일 내용은 답을 만들려고 Anthropic 서버로 전달됩니다. 그래서 회사 PDF 는 Claude 에게 보여 주지 않고, 규칙을 만들 때는 고객명·금액을 바꾼 샘플만 씁니다([04장](04_내_양식_가르치기.md)).
> - 채팅 탭에 PDF 를 올리거나 **Cowork 에 회사 PDF 를 맡기면** 그 순간 PC 밖으로 나갑니다. Cowork 작업은 Anthropic 서버에서 돕니다. 차이는 [01장](01_구조_이해.md)에 있습니다.
>
> Code 탭 찾는 길: Claude Desktop 위쪽(또는 왼쪽) 메뉴에서 「Code」 → 「폴더 열기」 → 이 저장소 폴더. 환경은 **「Local(로컬)」** 을 고릅니다.
> 버전마다 자리가 조금씩 다르니 **「Code」라는 글자를 찾으세요.** 안 보이면 [99장](99_막혔을_때.md) 첫 줄을 보세요.

> [!NOTE]
> **이 저장소에는 회사 정보가 하나도 없습니다.** 샘플은 전부 가짜(가짜 공급사 Vertex, 가짜 고객 ACME · Hanil)입니다.
> 여러분 회사 양식에 맞춘 규칙(`규칙.yaml`)과 장부·PDF 는 **여러분 PC 의 작업 폴더에만** 생깁니다.

## 무엇을 해 주나

**Invoice · DM(Debit Memo) PDF** 를 폴더에 넣고 `run.bat` 을 두 번 누르면

- `누적장부.xlsx` 에 문서 한 건이 한 줄씩 쌓이고 (품목은 「품목」 시트에)
- PDF 는 `정리문서\고객명\2026-10\Invoice_번호.pdf` 처럼 정리되고
- 읽지 못한 문서는 `확인필요\` 폴더에 사유 메모와 함께 모입니다.

매일 처리에는 Claude 가 끼지 않습니다. Claude 는 **내 양식에 맞는 규칙을 만들 때만** 씁니다.
고객 PO 가 엑셀로 오는 경우(회사 SO 양식으로 옮기기)는 2차 범위입니다([08장](08_선택_엑셀PO변환.md)).

## 필요한 것

| 항목 | 내용 |
|---|---|
| PC | Windows 10 · 11 |
| Claude 요금제 | **Pro 이상** (무료 요금제에는 Code 탭이 없습니다) |
| 설치 권한 | 프로그램을 깔 수 있어야 합니다 (회사 PC 면 IT 정책 확인) |
| PDF | 글자를 선택·복사할 수 있는 PDF. 스캔한 그림 PDF 는 읽지 못합니다 |

## 이 저장소 받기 (ZIP)

GitHub 이 처음이어도 됩니다. 아래 순서대로 누르세요.

1. 이 페이지 위쪽 오른편의 초록색 「**Code**」 단추를 누릅니다. (GitHub 의 단추입니다. Claude 의 Code 탭과는 다른 것입니다.)
2. 펼쳐진 목록 맨 아래 「**Download ZIP**」 을 누릅니다.
3. 받은 ZIP 을 `C:\dev\` 에 풉니다. 자세한 것은 [02장](02_설치.md)에 있습니다.
