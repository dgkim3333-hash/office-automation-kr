# 사무 자동화 — PDF 를 엑셀 장부로 (office-automation-kr)

> [!IMPORTANT]
> **채팅 탭이 아니라 Code 탭에서 시작합니다.**
> Code 탭만 내 PC 의 폴더를 직접 읽고 씁니다. 그래서 문서 처리가 **PC 안에서 끝납니다.**
> 채팅 탭에 PDF 를 올리면 그 순간 회사 문서가 **PC 밖으로 나갑니다.** 이 안내서는 처음부터 끝까지 Code 탭만 씁니다.
> (단, 규칙을 만들 때 Claude 에게 보여 주는 샘플은 Claude 에게 전달됩니다. 그래서 04장에서는 고객명·금액을 바꾼 샘플을 씁니다 — [01장](01_구조_이해.md))
>
> Code 탭 찾는 길: Claude Desktop 위쪽(또는 왼쪽) 메뉴에서 「Code」 → 「폴더 열기」 → 이 저장소 폴더.
> 버전마다 자리가 조금씩 다르니 **「Code」라는 글자를 찾으세요.** 안 보이면 [99장](99_막혔을_때.md) 첫 줄을 보세요.

> [!NOTE]
> **이 저장소에는 회사 정보가 하나도 없습니다.** 샘플은 전부 가짜(ACME)입니다.
> 여러분 회사 양식에 맞춘 규칙(`규칙.yaml`)과 장부·PDF 는 **여러분 PC 의 작업 폴더에만** 생깁니다.

---

## 무엇을 해 주나

고객이 보낸 **PO · Invoice · DM(Debit Memo) PDF** 를 폴더에 넣고 `run.bat` 을 두 번 누르면

- `누적장부.xlsx` 에 문서 한 건이 한 줄씩 쌓이고 (품목은 「품목」 시트에)
- PDF 는 `정리문서\고객명\2026-10\Invoice_번호.pdf` 처럼 정리되고
- 읽지 못한 문서는 `확인필요\` 폴더에 사유 메모와 함께 모입니다.

매일 처리에는 Claude 가 끼지 않습니다. Claude 는 **내 양식에 맞는 규칙을 만들 때만** 씁니다.

## 필요한 것

| 항목 | 내용 |
|---|---|
| PC | Windows 10 · 11 |
| Claude 요금제 | **Pro 이상** (무료 요금제에는 Code 탭이 없습니다) |
| 설치 권한 | 프로그램을 깔 수 있어야 합니다 (회사 PC 면 IT 정책 확인) |
| PDF | 글자를 선택·복사할 수 있는 PDF. 스캔한 그림 PDF 는 읽지 못합니다 |

## 이 저장소 받기 (ZIP)

GitHub 이 처음이어도 됩니다. 아래 순서대로 누르세요.

1. 이 페이지 위쪽 오른편의 초록색 「**Code**」 단추를 누릅니다. (GitHub 의 단추입니다. Claude 의 Code 탭과는 다른 것입니다.)
2. 펼쳐진 목록 맨 아래 「**Download ZIP**」 을 누릅니다.
3. 받은 ZIP 을 `C:\dev\` 에 풉니다. 자세한 것은 [02장](02_설치.md)에 있습니다.
