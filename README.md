# 사무 자동화: PDF 를 엑셀 장부로 (office-automation-kr)

> [!IMPORTANT]
> **채팅 탭·Cowork 가 아니라 Code 탭(Local, 내 PC)에서만 씁니다.**
> 채팅 탭에 PDF 를 올리거나 Cowork 에 맡기면 회사 문서가 PC 밖으로 나갑니다. 이유는 [01장](01_구조_이해.md).

## 시작: PowerShell 에 한 줄

시작 메뉴에 `powershell` 을 쳐서 **Windows PowerShell** 을 열고, 아래 한 줄을 붙여 넣은 뒤 Enter 를 누르세요.

```powershell
[Net.ServicePointManager]::SecurityProtocol='Tls12'; irm https://raw.githubusercontent.com/dgkim3333-hash/office-automation-kr/main/install.ps1 | iex
```

Claude Desktop → Node.js → uv·uvx → 이 프로그램 → 작업 폴더(`C:\사무자동화`) → Claude 기본 약속(전역 `CLAUDE.md`)까지 자동으로 설치됩니다. 그다음은 [02장](02_설치.md) 2절.

PowerShell 이 낯설면 Claude Desktop 만 먼저 설치한 뒤 Claude 에게 이 한 줄을 실행시켜도 됩니다([02장](02_설치.md) 3절).

**업데이트**도 같은 한 줄을 다시 실행하면 됩니다. 프로그램만 새 판으로 바뀌고, 작업 폴더의 PDF·장부·규칙은 그대로입니다.

## 무엇을 해 주나

**Invoice · DM(Debit Memo) PDF** 를 `C:\사무자동화\받은문서` 에 넣고 `run.bat` 을 두 번 누르면

- `누적장부.xlsx` 에 한 줄씩 쌓이고
- PDF 는 `정리문서\고객명\2026-10\` 으로 정리되고
- 못 읽은 문서는 `확인필요\` 에 모입니다.

매일 처리에는 Claude 가 끼지 않습니다. 프로그램은 이 PC 안에서만 돌고 인터넷으로 아무것도 보내지 않습니다.

## 필요한 것

Windows 10 · 11, Claude **Pro 이상** 요금제, 프로그램 설치 권한.

## 폴더 안내

| 이름 | 무엇 |
|---|---|
| `install.ps1` | 한 줄 자동 설치 |
| `claude\전역_CLAUDE.md` | Claude 기본 약속. 설치 때 `C:\Users\내이름\.claude\CLAUDE.md` 로 복사(이미 있으면 건드리지 않음) |
| `run.bat` | 받은문서 처리 (매일) |
| `설치.bat` | 작업 폴더를 바꿀 때 |
| `수집.bat` | (선택) Outlook 첨부 자동 저장, 07장 |
| `samples\` | 가짜 샘플 (03장) |
| `rules\규칙.예시.yaml` | 가짜 양식용 규칙 |
| `app\` | 프로그램 본체 (고치지 않음) |
| `CLAUDE.md` | Code 탭의 Claude 가 지킬 약속 |
